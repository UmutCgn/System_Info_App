# System_Info_App
Çokta profesyonel olmayan bu uygulamayı bilgisayar mühendisliği 2. sınıfta kullanacağım java dilini hatırlamak için 1 günde yazdım.
Bu programı yazarken Java dilini kullandım.
OSHI, Flatlaf gibi kütüphaneler kullandım.
OSHI ile birlikte gelen özellikleri temel alarak yaptığım için grafik kartları kısmına çok ilgi gösteremedim.
Timer kullanarak anlık CPU kullanımını , En çok RAM ve CPU kullanan uygulamaları çekip listeledim ve anlık olarak kullanımını gösteren bir sekme yaptım.
